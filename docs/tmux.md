# Tmux

```bash
# Create new session and window
tmux new -s main -n main

# Inside tmux, create new window
tmux new-window -n xxx

# Attach to last session
tmux a

# Detach
prefix + d

# Rename current window
prefix + ,

# Window list
prefix + w

# Surf windows
prefix + 1    # window 1
prefix + 2    # window 2
prefix + 3    # window 3

# Maximize pane
prefix + z

# Layout float
alt + shift + ; (enter service mode) then f
```
